# Amazon Ink Media Mix Model

## Business Objective

Build a media mix model to estimate daily unit sales for ink supplies sold on Amazon.com and identify the key factors that can drive incremental sales.

## Analytical Approach

The project will include:

1. Data understanding and validation
2. Exploratory data analysis
3. Historical-average baseline
4. Media carryover and saturation transformations
5. Media mix model development
6. Time-based model validation
7. Sales-contribution and marginal-effect analysis
8. Business recommendations

## Dataset

The simulated dataset contains daily product-level unit sales, selling price, paid search activity, display activity, radio activity, and website-engagement metrics.

The source dataset is excluded from GitHub. Place it locally at:

`data/raw/DMR_case_study_data.xlsx`

## Repository Structure

- `data/`: Raw and processed data
- `notebooks/`: Step-by-step analysis
- `src/`: Reusable Python functions
- `outputs/`: Model results, tables, and figures
- `presentation/`: Stakeholder presentation
- `tests/`: Unit tests
